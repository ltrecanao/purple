Productos

Escribí, pensá en equipo, visualizá.

Tres herramientas de Purple, cada una para un momento distinto del trabajo. Software libre, en el navegador.

  • Editor Markdown

    PurpleMD

    Editor Markdown liviano, autohospedado y de código abierto. Vista previa en vivo, exportación a PDF, Google Auth y Drive, e integración con MCP.

    • Vista previa en vivo
    • PDF
    • Google Drive
    • MCP
    Abrir PurpleMD (se abre en una pestaña nueva)
  • Pizarra colaborativa

    PurpleBoard

    Pizarra colaborativa peer-to-peer, open source y 100% estática. Creá notas, dibujá, conectá ideas y sumá imágenes mientras hablás con otras personas en tiempo real, sin backend y sin registro.

    • Peer-to-peer
    • Sin backend
    • Sin registro
    • Tiempo real
    Abrir PurpleBoard (se abre en una pestaña nueva)
  • Visualizador 3D

    Purple3D

    Visualizador 3D modular que funciona en el navegador sin instalar nada. Cada módulo resuelve un tipo de objeto: armado paso a paso, panelizado, control de faltantes y sobrantes y listado de corte exportable.

    • Modular
    • Paso a paso
    • Listado de corte
    • Sin instalar
    Abrir Purple3D (se abre en una pestaña nueva)

Purple3D

Módulos incluidos

Cada módulo resuelve un tipo de objeto: armado paso a paso, panelizado, control de faltantes y sobrantes y listado de corte exportable. Hoy Purple3D incluye tres.

  • Steelframing

    Estructuras livianas de perfiles de acero galvanizado, vistas y armadas en 3D.

    • Armado paso a paso
    • Panelizado
    • Faltantes y sobrantes
    • Listado de corte exportable

  • Drywall

    Tabiques y cielorrasos con placas de yeso, para ver cómo se colocan y cuánto material lleva.

    • Armado paso a paso
    • Panelizado
    • Faltantes y sobrantes
    • Listado de corte exportable

  • Woodframing

    Estructuras de entramado de madera, con cada pieza ubicada y contada.

    • Armado paso a paso
    • Panelizado
    • Faltantes y sobrantes
    • Listado de corte exportable

Solo para visualizar. Estos módulos no reemplazan el plano ni el cálculo estructural.

Para otros tipos de objeto, el desarrollo de módulos a medida está disponible como servicio. Ver Empresas
